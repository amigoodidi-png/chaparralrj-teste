# ChaparralRJ — prévia de teste

Cópia estática do site novo do ChaparralRJ, só para mostrar e testar, publicada pelo GitHub Pages.

- As páginas do site ficam aqui e não dependem do PC ligado.
- A pasta `loja/` é uma vitrine de demonstração com os produtos copiados da loja local. A compra e o pagamento continuam na loja oficial, com a mesma API de pagamento.
- O endereço da loja oficial fica em `loja/endereco-loja.js`. Quando o túnel for religado e o link `trycloudflare.com` mudar, troque essa linha.
